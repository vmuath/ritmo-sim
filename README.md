# ritmo-sim

Free iOS Simulator tests for **RITMO Dev** (https://preview.ritmoapp.pages.dev), the preview build of RITMO.
A GitHub-hosted Mac (free for public repositories) boots a simulated iPhone 16 Pro, adds RITMO Dev to its
Home Screen, drives it with XCUITest touches and records the screen.

Test scripts only: no app code and no personal data. The preview runs on its own storage with made-up test data.
